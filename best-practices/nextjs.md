## Nextjs

### Знания

- Понимать что такое серверные компоненты, чем они отличаются от клиентских. Где использовать 'use client', какие компоненты можно вкладывать друг в друга
- Понимать, что такое SSG, ISR, SSR, CSR — отличия, где что использовать
- Понимать, что такое hydration
- Знать App Router: как создавать роутинг, как работает layout.tsx, page.tsx и их очередность, группировка роутов с помощью круглых скобок и передача параметров с помощью квадратных скобок
- Уметь работать с next/image
- Уметь работать с next/dynamic
- Уметь использовать server actions
- Уметь работать с headers и cookies
- Уметь создать API route
- Уметь работать с middleware
- Уметь работать с кэшированием по времени, по тегу, по пути. Например, настроить api route для сброса по тегу
