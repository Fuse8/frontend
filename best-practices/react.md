## React

### Знания

- Понимать что такое JSX
- Понимать, как работает виртуальный DOM и когда происходят перерисовки, что такое батчинг
- Уметь работать с базовыми хуками (useState, useEffect, useMemo, useCallback, useRef) и кастомными хуками
- Понимать, где использовать useState, а где useRef
- Понимать жизненный цикл компонентов
- Понимать key в списках
- Понимать Context API
- Понимать, как работает StrictMode и зачем он нужен
- Понимать, как работает Suspense и React.lazy
- Понимать основы оптимизации рендеринга: мемоизация, разделение кода, избегание лишних перерендеров
- Понимать работу Event Delegation в React и отличие от нативных событий
- Понимать отличие контролируемых и неконтролируемых форм
- Уметь работать с рефами для управления фокусом
- Уметь работать с формами с помощью React Hook Form, валидировать с помощью zod
- Уметь работать с порталами и модальными окнами
- Уметь работать с состоянием, понимать где применить useState, а где Zustand
- Уметь работать с react-query
- Уметь работать с виртуальными списками (tanstack virtual)
- Уметь безопасно использовать dangerouslySetInnerHTML
