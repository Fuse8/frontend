## Оптимизация

### Знания

- Понимать tree shaking, уметь настроить или выбирать инструменты, в которых включен tree shaking
- Понимать critical rendering path
- Использовать font-display: swap для шрифтов
- Понимать что такое CDN
- Понимать Web Vitals и уметь оптимизировать (FCP, LCP, CLS, TTFB)
- Уметь использовать виртуализацию списков
- Уметь использовать debounce/throttle для часто вызываемых событий (scroll, input)
- Уметь использовать lazy loading для скриптов и картинок
- Уметь использовать preload/preconnect/prefetch
- Уметь использовать defer/async и понимать их отличие
- Уметь оптимизировать изображения webp и svg. Понимать srcset, sizes
- Уметь замерить производительность с помощью различных инструментов, lighthouse, dev tools profiler, React profiler
